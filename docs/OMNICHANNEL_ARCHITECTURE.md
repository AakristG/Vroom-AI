## How Nemotron reaches voice (Approach B — Custom LLM)

Spoken answers are **not** generated by a Retell Conversation Flow LLM as the primary brain.

Retell opens `WS /ws/llm/<call_id>/` → `RetellLLMConsumer` → `run_turn` → NVIDIA NIM Nemotron.

If the dashboard agent is still a Conversation Flow agent, it must be switched (or a second agent published) to **Custom LLM** with `llm_websocket_url` pointing at this Django ASGI server. Custom functions on a Conversation Flow agent can call our HTTP tools, but then Retell's model — not Nemotron — would still author the spoken turns. That violates “one shared Nemotron intelligence,” so Custom LLM is the chosen path.
