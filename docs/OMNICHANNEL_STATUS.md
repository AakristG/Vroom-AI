# Omnichannel implementation status (truthful)

## Architecture summary

One Django backend owns authorization and tools. Website chat (`/api/ai/assistant/`, `/api/ai/chat/`) and Retell Custom LLM WebSocket (`/ws/llm/<call_id>/`) both call `apps.ai.orchestrator.run_turn` → NVIDIA NIM Nemotron. Side-effect actions go through `apps.voice.actions` two-confirmation FSM. SpacetimeDB fans out events when running; SQLite remains account/action SoT.

## Retell ↔ Nemotron

- **Chosen path:** Custom LLM WebSocket (Approach B).
- Spoken answers are generated by **Nemotron on our server**, not by a Conversation Flow LLM.
- Current configured agent (`RETELL_AGENT_ID`) is still a **Conversation Flow** agent (`response_engine.type = conversation-flow`). Browser audio can connect once keys are set, but Nemotron is **not** the speaker until the agent is Custom LLM with `wss://…/ws/llm/`.
- Web-call mint uses Retell **`POST /v3/create-web-call`** (v2 is deprecated).
