# Vehicle category photos

The "Explore vehicles" cards on the home page load one photo per category from this folder. Until a file is added, that card shows the built-in illustration instead, so nothing breaks.

| File | Should show |
| --- | --- |
| `sedans.webp` | A current Toyota sedan (Camry, Corolla, or Crown) |
| `suvs.webp` | A current Toyota SUV (RAV4, Highlander, or 4Runner) |
| `trucks.webp` | A Toyota Tacoma or Tundra |
| `hybrids.webp` | A Toyota hybrid (Prius, Camry Hybrid, or Sienna) |
| `electric.webp` | The Toyota bZ4X or another Toyota EV |
| `minivans.webp` | The Toyota Sienna |
| `sports-cars.webp` | The Toyota GR86 or GR Supra |

Use the same style for all seven: a side or three-quarter view, a neutral or light background, and the vehicle centered with room around it. The card crops to 16:10, so export at 1200×750 WebP (about 80–150 KB each).

Only use images you have the right to use (your own photos, Toyota media with permission, or commercially licensed photos of the correct model). Don't use unrelated stock imagery. Keep a note of each image's source and license next to it.
