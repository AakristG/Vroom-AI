# Generated bindings — do not hand-edit

This folder is generated by the SpacetimeDB CLI from `spacetimedb/server/src/index.ts` and is
currently **empty** (just this placeholder). Generate it with:

```bash
cd spacetimedb/server
spacetime generate --lang typescript \
  --out-dir ../../frontend/src/spacetime/module_bindings \
  --module-path .
```

Re-run this any time `spacetimedb/server/src/index.ts` changes, then commit the result so
teammates without the `spacetime` CLI installed can still build the frontend.

Until this is generated, `frontend/src/spacetime/client.ts` won't type-check — that's expected
and fine, since nothing else in the app imports it eagerly.
